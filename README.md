# Bursr on Celo

Celo build of Bursr for the Celo "Agents Open for Business" hackathon (Loops House). All code in this repository was written from 20 Nov 2026.

Bursr is an AI finance team for African small businesses. It keeps a business's cash in dollars (USD₮), pays staff and suppliers in naira (cNGN), holds suspicious invoices before they are paid, and can never spend outside the limits the owner sets onchain.

Status: setting up. Steps to run it will be added here as each part works.
